# Mobile forest-stream background

The portrait mobile background was supplied directly by the project owner on August 8, 2026 for use in Stabilize.

The build reconstructs `mobile-forest-stream-v1-720.webp` from bounded source-payload chunks. The result is an optimized, static 720 × 1280 WebP that preserves the supplied 9:16 composition. It is decorative and selected only for portrait mobile layouts; desktop backgrounds remain unchanged.
