# Mobile forest-stream background

The portrait mobile background was supplied directly by the project owner on August 8, 2026 for use in Stabilize.

The build reconstructs `mobile-forest-stream-v1-540.webp` from bounded source-payload chunks and verifies its exact byte count, SHA-256 checksum, RIFF/WebP structure, dimensions, and static-image status. The result is an optimized 540 × 960 WebP that preserves the supplied 9:16 composition. It is decorative and selected only for portrait mobile layouts; desktop backgrounds remain unchanged.
