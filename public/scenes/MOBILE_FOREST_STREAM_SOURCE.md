# Mobile forest-stream background

The portrait mobile background was supplied directly by the project owner on August 8, 2026 for use in Stabilize.

The deployed `mobile-forest-stream-v1.svg` preserves the supplied 864 × 1536 composition and embeds an optimized JPEG copy so it can be committed through the text-only repository content workflow. It is decorative, displayed only on portrait mobile layouts, and remains static.
