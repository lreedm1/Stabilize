Privacy and memory

What Stabilize remembers

The current web tab can restore the conversation locally. Guest and private chats create no Stabilize account memory. Signed-in memory is condensed, viewable, correctable, and deletable.

Current web tab and unfinished drafts

The website keeps a bounded copy of the visible current thread in browser session storage for up to 24 hours, including the user's messages and Stabilize replies. This lets a refresh or ordinary navigation preserve the conversation. It is not sent to Stabilize as analytics. Starting a new chat or signing out clears it.

An unfinished non-private draft may be saved locally for up to seven days. Turning on private mode clears the saved draft and prevents a private draft from being retained. Static offline support never caches chat, API, authentication, billing, or memory responses.

Guest and private chat

Guest messages are processed for the current reply but are not written to Stabilize's server-side conversation memory. Private mode also bypasses signed-in account memory: it does not read the summary and does not record the exchange there. Private mode does not prevent the request from being processed by Cloudflare and OpenAI.

Signed-in memory

Google sign-in is optional and associates a one-way account alias—not an email address—with a rolling summary of at most 1,000 characters and no more than eight recent user/assistant messages awaiting condensation. The record expires 30 days after the last stored exchange.

From the site menu, signed-in users can view the raw summary and bounded recent context, save a correction, or immediately delete the complete memory record. The summary may be incomplete or wrong and is treated by the reply model as fallible background.

OpenAI processing

OpenAI processes ordinary reply requests and model-generated memory summaries. Stabilize sends both kinds of request with store: false, so it does not ask OpenAI to keep the resulting Responses objects as application state. OpenAI may still process and retain API inputs and outputs in abuse-monitoring systems under the deployment's applicable organization or project data controls and terms.

Other providers

Cloudflare hosts the website and Worker. Google handles optional sign-in. Stripe handles optional web subscriptions. GitHub stores optional detailed public feedback. Apple distributes the native iOS app and may process app-store and device diagnostics under its terms and device settings.

Feedback and operational logs

The one-tap “Is the next step clearer?” signal records only the selected rating and deterministic route—not the prompt, reply, or account. Optional detailed feedback remains public after the user acknowledges that fact. Stabilize does not intentionally log successful prompt or reply bodies, account aliases, or IP-derived conversation identifiers.

Native iOS app

Version 1 of the native app is guest-only and asks permission before first sharing a message through the Worker and OpenAI. It does not intentionally save a local transcript or include analytics, advertising, or tracking SDKs. Revoking future-send permission cannot recall data already transmitted.

Use caution

Do not enter passwords, authentication codes, financial account numbers, or information you do not want transmitted to the involved providers. Private mode is not confidential clinical care, anonymous networking, or a guarantee of zero retention anywhere.

Prototype status: This describes the intended current implementation. Broad promotion still requires independent privacy, security, accessibility, clinical, payment, and legal review.
