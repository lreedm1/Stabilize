1. Goal

One direction. Few signals. Repeated weekly execution.

⸻

2. Setup (Week 1–2)

Do a quick scan:

* time (real weekly free hours)
* commitments (fixed drains)
* active projects (what actually matters next 30 days)
* constraints (health/money/obligations)
* energy pattern

➡️ Cut anything not relevant in 30 days.

⸻

3. Choose (Week 3)

* 1 primary 12-week goal
* 2–3 measurable outcomes
* max 3 active priorities total

Everything else = paused / later.

⸻

4. Weekly Structure (Weeks 3–12)

A. Focus Blocks

* 3 protected blocks/week (60–90 min)
* same time each week if possible
* non-negotiable

⸻

B. Execution Rule

Each block uses:

If it’s scheduled → I start immediately

(no deciding inside the block)

⸻

C. Weekly Review (20 min)

Ask:

* What moved forward?
* What wasted time?
* What blocked me?
* What changes next week?

Then update:

* stop / start / continue
* next 3 actions
* next week blocks

⸻

5. Decision Filter (always on)

Before adding anything ask:

1. Does this help the 12-week goal?
2. Does this reduce overload?
3. Does this fit available time/energy?

If no → don’t add it.

⸻

6. Midpoint Reset (Week 8)

* keep / cut / simplify
* remove anything not pulling weight
* reduce complexity, not increase effort

⸻

7. Success Signal

You are doing it right if:

* priorities stay small
* focus blocks actually happen
* weekly review is consistent
* life feels simpler, not busier

⸻

8. Principle

Clarity comes from subtraction + repetition, not optimization.
