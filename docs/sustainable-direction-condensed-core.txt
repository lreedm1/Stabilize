Purpose

Use this when Direction feels like the weakest layer.

Weak direction is usually not a character flaw. It is usually a system problem:

* too many active commitments
* fuzzy goals
* weak filters
* no protected time
* intentions not translated into scheduled action
* too much planning, not enough feedback

The goal is not reinvention.
The goal is a simple direction system that survives real life.

⸻

Core Rule

Use one operating system:

Inventory reality → choose one 12-week objective → protect calendar blocks → use if-then rules → review weekly → prune overload.

Keep it boring. Boring systems work.

⸻

Direction Rules

1. One primary goal at a time
    * Use one main 12-week objective.
    * Keep active goals to three or fewer.
    * Park everything else as “later.”
2. Direction needs feedback
    * A goal without feedback becomes fantasy.
    * Track small leading indicators: blocks completed, outputs shipped, conversations done, review completed.
3. Calendar beats intention
    * If it is not scheduled, it is not protected.
    * Use recurring focus blocks before adding more tasks.
4. If-then beats motivation
    * Convert actions into rules:
    * “If it is Monday at 9 AM, then I open the project file and work for 60 minutes.”
    * “If I miss a block, then I reschedule it once, not abandon the week.”
5. Subtraction creates direction
    * Direction improves as much by removing commitments as by adding goals.
    * Stop-doing lists are not optional.
6. Capacity realism comes first
    * If real available time is under ~2 focused hours/week, do not run a full overhaul.
    * Use: one goal, one block, one review, one subtraction.

⸻

1. Intake: See the Actual Load

Record only what matters.

Commitments Inventory

Capture:

* roles you currently hold
* recurring commitments
* active projects needing attention in the next 30 days
* deadlines and consequences
* real discretionary hours per week
* best and worst energy windows
* current constraints
* resources and support
* stop-doing candidates

A project counts as active only if it needs real attention in the next 30 days.
Everything else goes to Later, not your weekly mind.

⸻

Project Score

For each active project, rate 1–5:

* value
* urgency
* strategic fit
* energy cost
* reversibility

Keep projects with high value + high strategic fit that fit your actual time budget.

Drop, pause, delegate, or renegotiate the rest.

⸻

2. Best Framework Stack

Use frameworks as tools, not religions.

Strongest Core

Goal-setting

Use specific, challenging goals with feedback.

Good goal:

Complete X by date Y, measured by Z.

Bad goal:

Get my life together.

⸻

Implementation intentions

Turn intent into action.

Formula:

If X happens, then I will do Y.

Examples:

* If it is 8 AM, then I open my weekly review note.
* If I feel avoidance, then I work for 10 minutes only.
* If I miss a block, then I reschedule once.

⸻

WOOP

Use when a goal is stuck.

* Wish: what do I want?
* Outcome: why would it matter?
* Obstacle: what will probably block me?
* Plan: if obstacle X happens, I will do Y.

Best for avoidance, procrastination, fear, or repeated derailment.

⸻

Time-blocking

Reserve calendar time for the priority.

Use blocks like:

* 1–3 weekly focus sessions
* 60–90 minutes each
* protected from optional tasks
* paired with an if-then start rule

⸻

Habit cues

Attach small repeated behaviors to stable cues.

Example:

After breakfast, I review today’s top 3 tasks.

Use for rituals, not complex projects.

⸻

Useful but Secondary

SMART

Good for rewriting vague goals into clearer goals.
Not a full direction system.

OKRs

Useful for a 12-week sprint:

* 1 Objective
* 2–4 Key Results

Avoid metric theater.

Eisenhower Matrix

Useful for daily triage.
Not a purpose system.

Pareto / 80:20

Useful for pruning and leverage.
Not a law of reality.

⸻

3. Goal Map

Map goals backward from horizon to next action.

For each important goal, define:

Layer	Question
Horizon	Is this 12 weeks, 6–12 months, or 2–3 years?
Outcome	What must be true at the end?
Motive	Why does this matter?
Capability	What skills must exist?
Support	What people, tools, money, or permissions are needed?
Sequence	What milestones come first?
Translation	What is the next action, calendar block, and if-then rule?

Only the shortest-horizon goal should be active at full intensity.
Longer goals are maps and filters, not daily demands.

⸻

4. Minimum Viable Direction System

Start with these.

1. Commitments Dump

Write every active role, project, deadline, obligation, and open loop.

Goal: reveal hidden overload.

⸻

2. Choose One 12-Week Objective

Format:

In 12 weeks, I will achieve ___, measured by ___.

Add 2–4 key results.

Example:

Build a durable direction system.
Key results: complete weekly review 10/12 weeks, finish 24 focus blocks, reduce active goals to 3 or fewer, ship one visible output.

⸻

3. Schedule Focus Blocks

Default:

* three 60–90 minute blocks/week

Low-capacity version:

* one 45–60 minute block/week

Put them on the calendar before adding tasks.

⸻

4. Write If-Then Start Rules

For each block:

If it is [time/cue], then I will [first tiny action].

Make the first action embarrassingly easy.

⸻

5. Make One Subtraction

Pause, delegate, renegotiate, or drop one low-value commitment.

Direction gets clearer when the board gets smaller.

⸻

6. Weekly Review

Once a week, 15–20 minutes.

Answer:

* What was the main objective?
* What measurable progress happened?
* What did I actually spend time on?
* Which blocks happened, moved, or failed?
* What obstacle repeated?
* What should I stop, continue, and start?
* What are next week’s top 3 commitments?
* What blocks are scheduled?
* What if-then rule protects the hardest block?

⸻

5. 12-Week Direction Reset

Weeks 1–2: Reality Check

* complete commitments inventory
* estimate real available hours
* map energy windows
* identify overload
* start stop-doing list

Output:

I know what is actually on my plate.

⸻

Weeks 3–4: Choose and Protect

* choose one 12-week objective
* write 2–4 key results
* cap active goals at 3 or fewer
* schedule recurring blocks
* write if-then rules

Output:

My priority has time and a start cue.

⸻

Weeks 5–8: Execute and Adjust

* complete focus blocks
* run weekly reviews
* use WOOP on avoided work
* fix friction
* keep pruning

Output:

The system is producing feedback.

⸻

Weeks 9–12: Consolidate

* review progress
* simplify tools
* ship or document one visible output
* choose what continues
* draft next 12-week objective

Output:

Direction becomes a repeatable cycle, not a mood.

⸻

6. Metrics to Track

Keep metrics few.

Track:

* active goal count
* planned focus blocks
* completed focus blocks
* weekly review completed: yes/no
* one main outcome metric
* clarity score: 1–5
* energy-fit score: 1–5

If a metric does not change decisions, drop it.

⸻

7. Tool Stack

Use fewer tools.

Default minimalist stack:

* one calendar
* one task list
* one weekly review note

Good setup:

* Google Calendar for time blocks
* Todoist or simple task list for capture
* one note for weekly review

Optional:

* Toggl for 1–2 weeks only if actual time is unclear
* Notion only if it does not become procrastination
* Sunsama if guided planning helps more than it costs

Rule:

Any tool not used in 14 days gets removed or ignored.

⸻

8. Common Pitfalls

Overcommitment

Symptom: more than 3 active goals.

Rule: one primary objective, two maintenance goals max.

⸻

Perfectionism

Symptom: planning exceeds execution.

Rule: first useful version.

⸻

Decision fatigue

Symptom: re-deciding daily.

Rule: default blocks and if-then rules.

⸻

Goal conflict

Symptom: every domain demands full intensity.

Rule: declare one primary domain for 12 weeks.

⸻

Metric theater

Symptom: tracking without decisions.

Rule: metrics must affect action.

⸻

Energy blindness

Symptom: deep work scheduled during predictable low-energy periods.

Rule: match hard work to high-energy windows.

⸻

Tool sprawl

Symptom: many apps, little movement.

Rule: one calendar, one task list, one review.

⸻

9. Pivot Rule

Pivot the method before the value.

If the goal still matters but execution fails, change:

* scope
* schedule
* cue
* support
* environment
* measurement

Pause the goal only if:

* real constraints make execution impossible
* it no longer fits values or strategic priorities
* it consistently cannibalizes a more important goal

⸻

Ultra-Short Version

When Direction is weak:

1. Dump all commitments.
2. Keep one 12-week objective.
3. Cap active goals at three.
4. Schedule focus blocks.
5. Write if-then start rules.
6. Review weekly.
7. Subtract one low-value commitment.
8. Track only what changes decisions.
9. Pivot method before abandoning the goal.

Best rule:

Direction is not found by thinking harder. Direction is built by reducing overload, protecting time, taking scheduled action, and reviewing feedback.
